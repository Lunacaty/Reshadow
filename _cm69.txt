feat(159 第二部分): 补齐剩余 3 项高阶优化

上一轮我把第二部分当成「4 项里只做了 1 项」，还错误地说另两项「文档未展开细节」。
重读文档后确认：第二部分有 4 项优化，优化 1/2/3 我从未动过。本轮全部补齐。

【优化 1】discover 去掉双重声明噪音
  旧：discover 1 from self:cardpool Choose(1)
  新：discover 1<Amulet> where ...
  动词已决定卡池、数量已写在动词后，再重复 from self:cardpool Choose(1) 是冗余。
  只在「非默认形态」时才补 from 子句；卡种提到尖括号，其余条件留在 where。
  解析端两种写法都认。

【优化 2】pay 缩进块
  旧：if ctr:faith >= 5:
          counter faith by -5
          <动作>
  新：pay faith(5):
          <动作>
  判据严格：无 else、条件是 ctr:X >= N、Then[0] 恰好是 counter X by -N。
  任何一条不满足就原样打印 —— 美化不能改变语义。
  这是文档特别点名的价值：人类漏写那个 if 就会 0 资源白嫖。

【优化 3】资源计数器动词化
  counter pp by 3        -> recover_pp 3 / spend_pp 3（负）
  counter max_pp by 1    -> gain_max_pp 1
  counter ep/sep by 1    -> recover_ep / recover_sep
  counter earth_sigil    -> gain_earth_sigil
  counter clues          -> gain_clues
  counter shadow         -> gain_shadows
  counter faith          -> gain_faith / spend_faith
  只在 Add 且增量为纯常量时启用；动态表达式与 Set/Fill 仍走 counter。
