fix: 牌组一览布局 —— 顶栏两行 + 网格列数自适应，右侧不再被裁

两个独立原因叠在一起：

1. 顶栏原本是单行 HBoxContainer，塞了返回 + 标题 + 5 个卡池页签 +
   3 个操作按钮 + 计数。总宽远超 1280，HBox 既不换行也不压缩，
   『卡包/卡池管理』『导入牌组代码』直接被窗口右缘裁掉。
   改为两行：行一标题与操作按钮，行二卡池页签（可横向滚动）。

2. 牌组卡的最小宽度是 433，不是设定的 280。
   实测 [_grid] 每格 min=433：底部一行塞了状态徽章 + 弹性垫片 +
   出战/编辑/复制/删除 四个按钮，各按钮的最小宽度加起来把卡撑宽了。
   433 x 3 + 间距 = 1339 > 可用 1232，所以右缘永远裁一张。
   改为：状态单独一行，四个按钮一行且尺寸收紧（72/52/52/34）。
   最小宽度降到 306，三列共 946，放得下。

3. 网格列数原本写死 4，改为按滚动容器实际宽度重算。
   注意用 _scrollHost.Size.X 而不是本视图 Size.X ——
   视图在 _Ready 阶段 Size 仍是 0，按 0 算永远得到默认列数。

4. 卡名 chip 从 ExpandFill 改为 ShrinkBegin，
   三张卡名各撑一份最小宽也是撑宽卡片的原因之一。
