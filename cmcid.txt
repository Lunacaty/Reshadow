fix(167): 积木端卡牌一律按卡 ID 指定，撤掉卡名选择器

上一轮 §2.4 我加的「从卡池选卡名」是错的 —— 本仓约定卡牌只认卡 ID。

## 改法
  act_summon / act_add_hand / act_transform / act_gain_crest 以及 default 兜底，
  全部改为 BuildIntSpin 输入 IntB（卡 ID），不再提供卡名下拉。
  画布标签改为「召唤 #90011110」「生成 #xxx 加入手牌」这类 ID 形式。
  BuildCardPicker 整体删除。

## 为什么必须用 ID
  编译端 DoSpawn 只认 n.CardId、DoTransform 只认 n.IntoCardId。
  只写卡名时卡面中文完全正确、编译零错误，但打出去会召唤一个 CardId=0 的白板空壳。
  卡名还会随改名/换语言漂移，按名查必然失效。

## 验证
  IntB=90011110 -> 编译 CardId=90011110 -> 反编译 IntB=90011110  往返完整。

## 门禁
  全部通过，无退化。
