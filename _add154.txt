# 附 · 156 号复审新增（2 张）

> 来源：`docs/156-155号复审结论.md` 的 R3 类。
> 原列入 155 号「需人工复审」，本轮已查证为**确定错误**，补录于此。

## 11042310  收集的显现 / Collection Manifest

- 种类：法术
- 费用：2
- 职业：Dragoncraft

**原文**
```
Deal 4 damage to a random enemy follower. If you have a Clue amulet in your hand,
discard a random Clue amulet and draw a card with a base cost of 5 or more.
```

**AST**
```
fanfare:
  deal 4 damage to opponent:board Random(1) where is Follower
  if ctr:clues >= 1 then move self:hand Random(1) where (has trait Clue and is Amulet) to Cemetery move self:deck Random(1) where prop:BaseCost($item) >= 5 to Hand
```

**AST 语义**
法术入场曲：对敌方战场随机 1 个随从造成 4 点伤害；随后若 `ctr:clues ≥ 1`，
把我方手牌中随机 1 张「持 Clue 兵种且是护符」移入墓场（弃牌），
并从牌堆随机取 1 张「原始费用 ≥ 5」的卡放入我方手牌。

**结论**：❌ 错误

**说明**：原文条件是「若你的**手牌里**有 Clue 护符」，判据应当对**手牌区**做存在性检验。
AST 用的 `ctr:clues` 是**战场上的可堆叠 Clue 护符层数**
（`BattleState.cs:487` 的 `StackableAmulets["clues"]`，
`SummonClue` 把层数从旧护符搬到新护符），与手牌无关。

后果：场上叠了 Clue 但手里没有时，条件错误成立；
手里有 Clue 但场上没叠时，条件错误不成立。

正确形态应为：

```
if count(self:hand All where (has trait Clue and is Amulet)) >= 1
```

**复审类**：R3（并同时命中 R1）

## 11043110  天噬抢劫犯 / Obliviationist Mugger

- 种类：随从
- 费用：4　攻击/生命：3/3
- 职业：Dragoncraft

**原文**
```
Fanfare: If you have a Clue amulet in your hand, discard a random Clue amulet and gain 1 max play point.

Evolve: Select an enemy follower on the field and deal it 3 damage.
```

**AST**
```
fanfare if ctr:clues >= 1:
  move self:hand Random(1) where (has trait Clue and is Amulet) to Cemetery
  counter max_pp Add 1
evolve manual:
  select opponent:board Choose(1) where is Follower
  deal 3 damage to $selected
```

**AST 语义**
①入场曲，守卫 `ctr:clues ≥ 1`：把我方手牌中随机 1 张「持 Clue 兵种且是护符」
移入墓场（弃牌）；对我方 max_pp 计数器 +1。
②进化时（仅手动进化）：玩家从敌方战场选 1 个随从造成 3 点伤害。

**结论**：❌ 错误

**说明**：与 `11042310` 同一病灶。原文条件是「若你的**手牌里**有 Clue 护符」，
AST 用 `ctr:clues ≥ 1`（战场上的 Clue 护符层数）作为判据，数据源错误。

正确形态应为：

```
if count(self:hand All where (has trait Clue and is Amulet)) >= 1
```

**复审类**：R3
