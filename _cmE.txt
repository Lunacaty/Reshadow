fix: 立绘贴合拱形内框 + 入场动画重复 + 我方无法攻击敌方随从

【1. 立绘与边框之间的黑边】
  你说得对 —— 卡框本来就是代码画的，立绘形状应该直接由它推导。
  之前我另写了一条贝塞尔曲线去近似拱形，形状和内框对不上，
  两者之间就露出了一圈底色。

  改为：InnerOutline() 与 DrawFollowerArch/DrawAmuletFrame 里那个
  inner 多边形**共用同一组坐标**，再用扫描线 SpanAt() 按行求边界。
  形状必然严丝合缝。

【2. 入场动画播两遍】
  召唤一张卡时内核**同时**发 OnEnterField 与 OnSummon
  （后者是给「召唤时」能力用的语义事件）。
  UI 的 switch 把两个 case 写在一起，于是入场动画播了两次。
  改为只认 OnEnterField。

【3. 我方随从打不了敌方随从，但能打主战者】
  根因是我自己上一轮改坏的：
  为了让不足 5 个随从时居中，容器从 _board → HBoxContainer
  变成了 _board → CenterContainer → HBoxContainer。
  而攻击目标判定里写的是 _boardFoe.GetChildren().OfType<HBoxContainer>()，
  中间多一层就取不到任何棋子 —— 循环一次都不执行，
  于是只剩前面那段「打主战者」的分支能走通。全程没有任何报错。

  修法：抽出 BoardUnitsOf() 做深度遍历，不再写死层数。
  顺带修掉另一处 bug：原来 return 写在 if 外面，
  第一个不匹配的棋子就会退出整个循环。

新增 BUG-4 门禁（战斗 UI 30 → 31）：
  深度遍历存在=True 攻击用它=True 冲锋用它=True 无写死层数=True
