fix(109 内核侧): 战斗/进化/回合事件全部写入 EventLog

这是「伤害数字、进化动画、攻击冲撞全是空气」的真正原因。

【根因】
  BattleState.EmitEvent 同时做两件事：写 EventLog + 经 TriggerSink 转发给 VM。
  但 CombatResolver 与 TurnRunner 里大量地方直接调 vm?.EnqueueEvent()，
  **绕过了 EventLog**。
  前端 ConsumeNewEventsToVfx 读的是 State.EventLog ——
  手动进化、超进化、随从攻击掉血、吸血回复这些事件根本没被记录，
  所以前端读到 0 条，自然什么都不播。

【修改】
  1. VmEvent 增加 KnockedBackBySuperEvolve
     超进化随从击杀时由后端在事件上打标，前端不再靠易丢失的全局布尔猜测。

  2. BattleState.DestroyEntity / ProcessStateBasedActions 增加 bySuperEvolved 参数，
     OnDestroy 事件带上该标记。

  3. CombatResolver 全部事件改走 EmitOrEnqueue（优先 _state.EmitEvent），
     DestroyEntity / ProcessStateBasedActions 传入 attacker.IsSuperEvolved。
     共转换 8 处（OnAttack / OnClash ×2 / OnDamaged ×2 / OnHealed / 等）。

  4. TurnRunner 同样处理：新增 EmitOrEnqueue 辅助，
     转换 9 处（TurnStart / TurnEnd / OnEvolve / OnSuperEvolve /
     OnPlay ×4 / OnCountdownExpire ×2 / OnSpellboost / OnEngage / OnFuse），
     并给事件补上 PlayerId（原来 TurnStart/TurnEnd 都没有）。
